# 実装計画: 卒業制作発表用PowerPointスライド（.pptx）＆8分発表原稿の制作

情報科・情報実習の卒業制作発表（持ち時間約8分）に向け、プレゼンテーションのプロとして洗練されたスライド資料（.pptxファイル）と、スライドのノート部分に埋め込まれる完全な発表原稿（約2,000〜2,200文字）を制作・提供します。

---

## 発表の設計方針

### 1. スライドデザイン方針（文字最小限・ビジュアル重視）
- **1スライド1メッセージ**: 文字の詰め込みを完全排除し、大きな見出し（Key Message）、要点キーワード（3点以内）、およびMusic Pickerの実際のUIスクリーンショットを大きく配置。
- **情報科らしいダークモダン配色**: アプリのトーン＆マナーに合わせたハイコントラストな配色（黒背景 `#121214`、鮮やかなSpotifyグリーン `#1ed760`、アクセントレッド `#fa2d48`、白文字）。
- **アプリ画面写真の活用**: 実際のUIスクリーンショット（気分分析、アーティストディスコグラフィ、アルバム全曲再生、リアルタイム歌詞）を各スライドに最適レイアウト。

### 2. 発表原稿（スピーカーノート）方針（8分間構成）
- **文字量**: 約2,000〜2,200文字（日本語発表の標準速度：1分あたり250〜280文字）。
- **構成**: 各スライドに約50〜70秒分の読み原稿をスピーカーノート（PowerPointの発表者ツールで手元に表示されるノート領域）として正確に埋め込み。
- **情報科向けアピール**:
  - なぜ作ったか（開発動機・既存サービスの課題）
  - システムアーキテクチャ（Gemini AI + Spotify Web API + Express）
  - 直面した技術的課題（Spotify APIの403制限の回避、ノイズ曲フィルタリング、再生クロック同期など）
  - UI/UXの試行錯誤と解決

## 技術的な実装アプローチ

1. **`pptxgenjs` を利用した高品質 `.pptx` 生成スクリプトの作成**:
   - Node.jsライブラリ `pptxgenjs` をインストール。
   - スライドレイアウト（16:9 ワイドスクリーン）、ダークテーマ背景、タイポグラフィ、シェイプ、ローカル画像（スクリーンショット）埋め込みを自動化。
   - スライドごとに `slide.addNotes(speakerNotesText)` を設定し、PowerPointで開いた際に発表原稿が手元で読めるように組み込み。
2. **ダウンロードルート・UIの設置**:
   - サーバー側に `/api/download-presentation` エンドポイントを開設。
   - スライド生成スクリプトを実行し、ブラウザから `graduation_presentation_music_picker.pptx` を直接ダウンロード可能にする。
3. **Markdown発表原稿ファイルの保存**:
   - 万が一PowerPoint以外の印刷・カンペ用としても手元で読めるよう、スライド毎の全文原稿を `docs/presentation_script.md` にも出力。

3. **原稿の分量・時間検証**:
   - 発表原稿の文字数を計測し、標準朗読速度（300文字/分）で約7〜8分に収まることを検証。
