# 実装計画: 音楽体験向上のための5大機能の実装

ユーザー様にご指定いただいた5つの機能（ディスコグラフィの横スワイプ、全曲一括再生、曲行アクション統一、検索履歴・おすすめアーティスト、歌詞文字サイズ＆全画面表示）を実装します。

---

## 提案する変更内容

### 1. ディスコグラフィ & 検索アルバムの「横スワイプ（カルーセル）」対応
- **UI/UX**:
  - 選択された「スワイプのみで展開ボタンは不要」に準拠し、アルバム表示コンテナ（`.artist-albums-grid`）を横一列のスクロールスナップ式カルーセル（`overflow-x: auto; scroll-snap-type: x mandatory; flex-wrap: nowrap;`）へ刷新。
  - スクロールバーは非表示にし、スマホでは指でスムーズにスワイプ、PCではホイールやタッチ操作で自然に閲覧可能に。
  - 不要となった「もっと見る」「すべて表示」ボタンを非表示化・整理。
- **対象ファイル**:
  - `public/style.css`
  - `public/script.js`
  - `public/index.html`

### 2. アルバム詳細ページの「全曲一括再生」ボタン
- **UI/UX**:
  - アルバム詳細画面のヘッダーメタ情報部分に、Spotify / Apple Musicスタイルの緑色・丸型アイコン付きの目立つ **「全曲再生（▶）」** ボタンを配置。
  - ボタン押下時、アルバムの全曲（`albumTracks`）を再生キュー（`currentPlaylist`）に一括セットし、1曲目から自動で連続再生を開始。
- **対象ファイル**:
  - `public/index.html`
  - `public/style.css`
  - `public/script.js`

### 3. 曲リストすべてでの「お気に入り（ハート）」と「Spotifyで聴く」ボタンの統一
- **UI/UX**:
  - 現在の検索結果テーブルだけでなく、**アルバム詳細ページの収録曲リスト（`.album-track-row`）** および **アーティスト詳細ページの人気曲（`.artist-top-song-row`）** にも、お気に入り（ハート）ボタンとSpotifyアイコンを配置。
  - ハート押下でお気に入り（`localStorage`）への登録・解除が即座に反映され、行全体の楽曲再生クリックと干渉しないようイベントバブリングを制御。
- **対象ファイル**:
  - `public/style.css`
  - `public/script.js`

### 4. 検索履歴・人気アーティストのクイックタップ
- **UI/UX**:
  - 検索入力欄が空の初期状態、またはフォーカス時に、入力欄の下に以下の2つのセクションを表示：
    1. **最近の検索履歴**: 直近の検索キーワード（最大6件、個別の削除および「履歴をクリア」ボタン付き）。
    2. **おすすめアーティスト**: Vaundy, YOASOBI, back number, Official髭男dism, Ado, 米津玄師, Mrs. GREEN APPLE などのクイックチップ。
  - チップをタップすると、入力欄に自動入力されて即座に検索が実行されるスムーズなUXを実現。
- **対象ファイル**:
  - `public/index.html`
  - `public/style.css`
  - `public/script.js`

### 5. 歌詞画面の「文字サイズ調整」と「全画面表示（フルスクリーン）」
- **UI/UX**:
  - 歌詞ビュー（`#fpLyrics`）の上部に専用のツールバーを追加：
    - **文字サイズ変更**: 小（15px）・中（19px）・大（24px）を切り替え可能にし、設定を保持。
    - **全画面表示（フォーカスモード）**: プレイヤーの他の要素を最小化し、歌詞だけに集中できるフルスクリーン歌詞表示モード。
- **対象ファイル**:
  - `public/style.css`
  - `public/script.js`
  - `public/index.html`

1. **ディスコグラフィの横スワイプ（カルーセル）**:
   - `scroll-snap-type: x mandatory` によるスムーズな指スワイプ・スクロールを実現。「もっと見る」ボタンを非表示化し、すっきりとしたネイティブアプリ風のUIに刷新。
2. **アルバム詳細ページの「全曲一括再生」ボタン**:

4. **検索履歴 & おすすめアーティストのクイックタップ**:
   - 検索入力欄の下に「🕒 最近の検索」（履歴削除機能付き）と「🔥 話題・人気のアーティスト」（Vaundy, YOASOBI, back number, Mrs. GREEN APPLE など）を表示。ワンタップで即時検索実行。
5. **歌詞の「文字サイズ調整」と「全画面表示」**:
   - 歌詞画面上部にツールバーを新設。「小」「中」「大」のワンタップサイズ変更と、すりガラス背景の没入感あふれる「⛶ 全画面」表示モードを追加。
