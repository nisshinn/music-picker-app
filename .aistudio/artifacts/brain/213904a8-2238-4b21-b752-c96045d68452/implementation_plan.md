# アーティスト全曲取得・セッション既表示曲除外・未表示曲からのAI優先選曲 改修計画

## 課題の背景と分析
- **現状の問題点**:
  - 現在の実装では、Spotify検索の上位トラック（同一の30〜80曲の固定リスト）を取得しており、毎回同じ上位候補がAIに渡されていました。そのため、「別の5曲を引き直す」や再選曲を行っても、AIが同じ有名曲（例: back numberなら「水平線」「ハッピーエンド」「花束」など）を上位として選び続け、曲順が変わるだけで曲の顔ぶれが変わらない現象が発生していました。
  - 「別の5曲を引き直す」の除外対象が直前1回の5曲のみに留まっており、2回以上の引き直しや再選曲で以前の曲がすぐ復活していました。
- **ユーザーのご要望と回答**:
  1. アーティストの全楽曲をしっかりと広範囲に取得する（アルバム・シングル・人気曲の網羅）。
  2. 今回のセッションで一度表示した曲をすべて除外リスト（`sessionShownTrackUris`）に蓄積し、「別の5曲を引き直す」を押した際は過去に表示した曲をすべて除外して完全に新しい曲を提示する。
  3. 未表示曲のプールの中から、ユーザーが指定した「気分」に最も調和する5曲をAI（Gemini）が優先的に厳選する。

---

## 改修の設計仕様

### 1. アーティスト全楽曲の包括的取得（バックエンド: `server.js`）
- **`getFullArtistCatalogue(token, artistId, artistName, market)` 関数の新設 / 強化**:
  - Spotify Web API を活用し、単一の検索クエリだけでなく以下を包括して取得:
    1. アーティストのトップトラック (`/v1/artists/{id}/top-tracks?market=JP`)
    2. アーティストの全アルバム・シングル一覧 (`/v1/artists/{id}/albums?include_groups=album,single&limit=50&market=JP`) から各アルバムのトラックを取得
    3. クエリ検索 (`artist:"{artistName}"`)
  - 重複トラック（同一タイトルやリマスター重複、同一URI）を統合・ユニーク化し、100曲〜200曲規模の充実したディスコグラフィ（全楽曲カタログ）をメモリまたは短期キャッシュに構築。

### 2. セッション既表示曲の追跡と除外（フロントエンド: `public/script.js`）
- **`sessionShownTrackUris`（セッション既表示曲セット）の導入**:
  - 選択中アーティストについて、一度画面に表示された5曲のURIをセッション管理用のSet/配列に記録。
  - 「別の5曲を引き直す（reshuffle）」ボタン押下時、および同一アーティストでの再選曲時、これまでに表示されたすべての楽曲URIを `excludedTrackUris` としてバックエンドへ送信。
  - 未表示の楽曲が5曲未満になるまで一度も同じ曲が出ないことを保証。
  - （もしアーティストの全曲をすべて聴き終えた場合は、セッション履歴を自動リセットして再び最初から選出可能とする安全設計）。

### 3. 未表示曲プールからのAI気分優先選曲（バックエンド & フロントエンド）
- **バックエンド選曲フロー**:
  1. アーティストの全楽曲カタログを取得。
  2. セッション既表示曲（`excludedTrackUris`）およびバージョン条件・最近再生履歴でフィルタリングし、**完全に未表示の候補曲プール**を作成。
  3. 未表示の候補曲プール（最大30〜50曲）をGemini AIキュレーターに提示。
  4. Geminiが「指定された気分（例: 落ち着きたい、切ない、テンション高い等）」に最もふさわしい5曲を厳選し、それぞれの推薦理由（reason）と雰囲気タグを付与して返却。
- **フロントエンド表示**:
  - 毎回異なる新しい5曲と、それぞれの推薦理由・キュレーターメッセージを滑らかに画面表示。
  - トースト通知で「🎲 新しい5曲をセレクトしました！」を表示。

## 実装ステップ

1. **バックエンド (`server.js`) の改修**:
   - `getFullArtistCatalogue` を実装し、アーティストのアルバム・シングル・トップトラックから全楽曲を網羅的に取得・ユニーク化する処理を追加。
   - `/api/artist-tracks` および `/api/gemini/recommend-from-mood` において、`excludedTrackUris` に含まれる既表示曲を厳格に除外し、未表示プールからAI気分ランキングを行うよう強化。
2. **フロントエンド (`public/script.js`) の改修**:
   - `sessionShownTrackUris` によるセッション既表示曲トラッキングの実装。
   - 「別の5曲を引き直す」押下時にこれまで表示したすべての曲を除外パラメータに含めるよう改修。
   - アーティスト変更時はセッション既表示曲を適切に初期化。
3. **テストの拡充と検証 (`tests/spotify-browsing.test.js`)**:
   - 連続して引き直した場合に、既表示曲が一切重複せず未表示曲から気分選曲されることを検証するユニットテストを追加。
   - `npm test` による全テストの合格確認。
