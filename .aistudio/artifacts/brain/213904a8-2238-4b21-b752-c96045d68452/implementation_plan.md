# 歌詞文字サイズ設定の移動・全画面ボタン削除・アイコン再読み込みボタン追加の改修計画

## 概要
ユーザーからの指示を反映し、以下の仕様で改修を実施します：
1. **歌詞表示画面（`#fpLyrics`）上部の整理**: 文字サイズバー（`fp-lyrics-toolbar`）および全画面ボタンを完全撤去し、元のすっきりとした歌詞表示に復元。
2. **サイドメニュー（`#sideMenu`）への配置**: メニュー項目として「歌詞サイズ [小] [中] [大]」のセグメントボタンを直接配置。
3. **設定ページ（`#settingsPage`）への配置**: 「歌詞・表示設定」セクションを新設し、小・中・大の文字サイズ切り替えボタンを配置。
4. **歌詞フッター右側のアイコン再読み込みボタン**:
   - `image_6750be33.png` で示されたフッター右側の空きスペースに配置。
   - 「再読み込み」という文字は含めず、`image_9d79ccd0.png` や `LRCLIB ↗` の控えめで洗練された雰囲気に調和する**アイコンのみの再読み込みボタン**（回転矢印アイコン）として実装。
   - 歌詞が表示されなかった時や通信エラー時、あるいは手動で更新したい時にいつでも1タップで再取得可能。
5. **文字サイズの同期**: `localStorage` を利用し、サイドメニュー・設定ページ間の選択状態（小・中・大）および歌詞画面のサイズスタイルを瞬時に連動。

---

## 決定事項の確認
- **歌詞画面上部**: 文字サイズバーおよび全画面ボタンを削除し、以前のレイアウトに復元。
- **全画面ボタン**: 不要のため完全廃止。
- **再読み込みボタン**:
  - テキスト（「再読み込み」）は含めず、アイコン単体で配置。
  - 既存のフッター（`LRCLIB ↗`）の右端に配置し、曲再生中や歌詞未取得時でも邪魔にならず自然に溶け込むミニマルなデザイン。
  - ツールチップ（`title="歌詞を再読み込み"`）およびアクセシビリティ用ラベル（`aria-label="歌詞を再読み込み"`）を付与。

## 実装ステップ

1. **マークアップの更新 (`public/index.html`)**:
   - `#fpLyrics` 上部の `.fp-lyrics-toolbar` を削除。
   - `.fp-lyrics-footer` 内の再読み込みボタンを、テキストなしのアイコンボタン（`#fpLyricsRetry`）として右端に常設（歌詞未取得時にもすぐ押せる状態）。
   - `#sideMenu` に「歌詞の文字サイズ」セクションと `.lyrics-size-btn`（小・中・大）を追加。
   - `#settingsPage` に「歌詞・表示設定」セクションと `.lyrics-size-btn`（小・中・大）を追加。

2. **スタイルの整備 (`public/style.css`)**:
   - `.fp-lyrics-footer` のアイコンボタン（回転矢印）を、`LRCLIB ↗` の控えめなトーンと統一感を持ったサイズ・余白・ホバー色に調整。
   - サイドメニューおよび設定ページの文字サイズボタングループのスタイリング。
   - 不要となった全画面スタイル（`.is-fullscreen` 等）を削除。

3. **スクリプトの調整 (`public/script.js`)**:
   - `loadLyrics(force = true)`: 再読み込みボタンクリック時にキャッシュをクリアして再取得を実行。
   - `setLyricsSize`: サイドメニューと設定ページの `.lyrics-size-btn` のアクティブ状態を同期。
   - 全画面切り替えロジックを整理。

4. **検証**:
   - `npm test` による全テストの合格確認。
   - 歌詞未取得時・再生時の再読み込み動作確認。
