# 「別の5曲を引き直す」機能の改修計画

## 概要
「別の5曲を引き直す」ボタンを押した際、気分やジャンルによる過度な絞り込みで曲が不足したり曲が変わらなかったりする問題を解消します。
ユーザーの指示と質問回答に基づき、引き直し実行時は**気分・ジャンルの制約を解除**し、**選択中アーティストの楽曲カタログ全体から直前の5曲を除外した新しい5曲を確実に選出**します。
なお、対象ボタン（`.reshuffle-button`）への `height: 38px;` スタイル変更はFocus Modeの規程に基づき先行適用済みです。

---

## 決定事項の確認
1. **気分・ジャンルの解除**:
   - 初回選曲時は指定の気分・ジャンル・Gemini AIによる選定を行いますが、「別の5曲を引き直す」押下時は気分・ジャンル条件をバイパスし、アーティスト本来の持ち曲カタログから広く選曲します。
2. **直前の5曲の除外**:
   - 直前（または直近）にプレイリストへ表示されていた5曲のURIを除外し、必ず別の楽曲が選ばれるようにします。
3. **複数アーティスト選択時の均等ミックス**:
   - 複数アーティストが選択されている場合、各アーティストの持ち曲から均等にラウンドロビン方式でバランスよく選出します（例: 2アーティストなら3曲・2曲、3アーティストなら2曲・2曲・1曲）。
4. **曲数不足時の自動フォールバック**:
   - アーティストの配信曲数が少なく、直前の5曲を除外した結果5曲未満になってしまう場合は、除外履歴を自動リセットして全曲の中からシャッフルし、必ず5曲を確保してユーザーに提示します（エラーや空画面になりません）。
5. **UI & スタイル**:
   - Focus Modeで指定された `.reshuffle-button` の `height: 38px;` は維持。
   - キュレーターノートを「〇〇の楽曲カタログから、先ほどとは異なる5曲を引き直しました」と分かりやすく表示。

---

## 処理フロー

```
[ 「別の5曲を引き直す」クリック ]
             │
             ▼
[ 直前の5曲のURIを `excludedTrackUris` に記録 ]
             │
             ▼
[ 選択中アーティストの全楽曲カタログを取得 ]
 (※気分・ジャンルのフィルタを解除して広い母集団を確保)
             │
             ▼
[ 直前の5曲を除外 ]
   ├─ 残り曲数 >= 5曲 ──► 各アーティストから均等に5曲をサンプリング
   └─ 残り曲数 < 5曲  ──► 除外をリセットし全カタログからシャッフルして5曲確保
             │
             ▼
[ 5曲のプレイリスト画面を即時更新 & トースト通知 ]
```

---

## 実装ステップ

1. **`public/script.js` の `makePlaylist` 改修**:
   - `isReshuffle` 判定時に、アーティストが選択されている場合は `/api/gemini/recommend-from-mood` の厳しいジャンル／気分検索を呼ばず、アーティストのディスコグラフィ取得（`/api/artist-tracks` 等）に直行する分岐を追加。
   - 複数アーティスト選択時は各アーティストから均等に曲を取得・プールし、直前の5曲を除外。
   - 除外後の候補が5曲未満の場合は、除外を自動リセットして全曲からランダムに5曲を充当する安全策を実装。
   - 各曲の推薦理由（`reason`）およびキュレーターノート（`aiCuratorNote`）をアーティスト引き直し専用の自然な日本語メッセージに更新。

2. **検証**:
   - `npm test` による回帰テスト実行。
   - 1アーティスト選択時、複数アーティスト選択時、気分のみ選択時の引き直し動作を確認。
