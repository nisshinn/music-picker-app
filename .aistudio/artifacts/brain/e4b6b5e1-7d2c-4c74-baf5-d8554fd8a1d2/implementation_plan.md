# Apple Music風トラックリスト刷新 & アーティスト操作改善

余白過多となっていたトラック行の「#1」バッジを全画面から撤廃し、Apple Music風の洗練されたコンパクトな曲リスト（画像4参考）へ刷新するとともに、アーティスト検索のワンクリック追加、専用ページ遷移ボタン、検索ページでのアーティスト表示、人気曲10曲化とクリック再生を実装する計画です。

> [!IMPORTANT] ユーザー確認済みの決定事項
> - **ホームのアーティスト候補操作（画像2）**: アイコンや名前を含む行全体をクリックでワンクリック検索条件追加。右端ボタンを「プロフィールアイコンと矢印（👤 ›）」に変更し、そこをクリックした時にアーティスト専用ページへ遷移。
> - **曲を検索ページ（画像1）**: 楽曲リストの最上部にApple Music風の丸アイコン＋名前の「アーティスト」カード枠を表示し、クリックでアーティストページへ遷移。
> - **アーティストページのTop Songs**: 人気曲を10曲表示に拡大し、曲行をクリックすると即座にアプリ内プレイヤーで再生が開始される仕様に変更。
> - **全リストの余白・デザイン刷新（画像3→画像4）**: プレイリスト、ライブラリ（お気に入り）、履歴、検索結果など全画面から不要な「#1」バッジと上下の過度な余白を完全削除。曲名・アーティスト・アルバム・再生時間が整然と並ぶApple Musicライクな高密度テーブル/リストへ統一。

---

## 1. 概要と提供価値

### 解決する課題
1. **トラック一覧の余白過多（画像3）**: 現在各トラックの上に赤い「#1」「#2」バッジが独立して配置され、上下に不自然な巨大余白が生まれている問題を解消。
2. **アーティスト追加の煩雑さ（画像2）**: ホームでアーティストを条件に入れたい時、行クリックが詳細ページ遷移になっていたため、直感的にワンクリックで追加できるよう役割を反転。
3. **検索ページでのアーティスト導線欠如（画像1）**: 曲検索でアーティスト名（例: vaundy）を入れた際に、曲だけでなく該当アーティストの公式プロフィールカードを最上部に提示。
4. **アーティストページの人気曲**: 5曲から10曲へ拡充し、行をクリックするだけで即座に試聴・再生可能にする。

## 2. UI・ビジュアルデザイン設計

### A. Apple Music風トラックリスト（画像4準拠のレイアウト）
```
┌────────────────────────────────────────────────────────────────────────┐
│  曲               アーティスト         アルバム              時間       │
├────────────────────────────────────────────────────────────────────────┤
│ [▶] [Artwork] 曲名   アーティスト名       アルバム名           3:45  ♡ ↗ │
│ [▶] [Artwork] 曲名   アーティスト名       アルバム名           4:12  ♡ ↗ │
│ [▶] [Artwork] 曲名   アーティスト名       アルバム名           5:08  ♡ ↗ │
└────────────────────────────────────────────────────────────────────────┘
```
- **「#1」バッジの完全撤廃**: 上部の赤い独立バッジを全画面（プレイリスト、検索、お気に入り、履歴）から削除。
- **コンパクトな垂直リズム**: 行の高さを適正化（`min-height: 52px`、上下パディング 8px）。
- **ホバー・アクティブ表現**:
  - 行ホバー時にジャケット上に再生アイコン（`▶`）がスムーズにオーバーレイ。
  - 行クリックでその曲の再生（Spotify Playback SDK / プレビュー）を即時開始。
  - 再生中の曲はアクセントカラーと等化アニメーションで明示。
- **情報配置**:
  - デスクトップ: 「曲名」「アーティスト」「アルバム」「時間」「お気に入り/リンク」を整然としたグリッド/フレックスで表示。
  - モバイル: ジャケット・曲名・アーティスト・アクションを最適に凝縮し、横スクロールなしで快適に閲覧。

### B. ホームのアーティスト検索候補（画像2の改善）
```
┌────────────────────────────────────────────────────────┐
│  [入力欄] vaundy                                       │
├────────────────────────────────────────────────────────┤
│  (クリックで条件に追加)                        (詳細へ) │
│  [● Vaundy画像]  Vaundy                     [ 👤 › ]   │
│  [● 藤井風画像]  Fujii Kaze                 [ 👤 › ]   │
└────────────────────────────────────────────────────────┘
```
- **行全体クリック**: タップ/クリック1発で `selectedArtists`（最大3組）に即座に追加。
- **右端のボタン**: `[ 👤 › ]`（プロフィールアイコン＋矢印）に変更。ここを押すとApple Music風のアーティスト詳細ページへ遷移。

### C. 「曲を検索」ページでのアーティスト最上部表示（画像1の改善）
- 検索キーワードにマッチするアーティストが見つかった場合、検索結果の一番上に「アーティスト」見出しと円形アイコン付きカードを大きく表示。
- クリックでシネマティックなアーティスト専用ページへ直接ジャンプ。

## 3. 主要な設計決定とトレードオフ

1. **トラック行のクリック操作**:
   - **決定**: トラック行のどこをクリックしても曲を再生（お気に入りボタンや外部リンクボタンはイベント伝播を停止）。
   - **理由**: Apple MusicやSpotifyのネイティブな挙動に一致し、直感的で素早く試聴できるため。
2. **テーブルヘッダーのレスポンシブ対応**:
   - **決定**: デスクトップでは画像4のように「曲」「アーティスト」「アルバム」「時間」の見出しを控えめに表示し、モバイル（幅640px以下）では自動でコンパクトな2行表示に切り替え。
   - **理由**: 小さい画面で無理なテーブル幅による文字つぶれを防ぎつつ、PC大画面では画像4の洗練されたデスクトップUIを完全に再現するため。

## 4. 技術アーキテクチャ & 実装計画

### データフロー図
```
[ ユーザー操作 ]
   │
   ├── ホームのアーティスト検索
   │      ├── 行をクリック ──> addArtistToSelection(artist) ──> タグ反映
   │      └── 右端 [👤 ›] ──> openArtistDetailPage(artist) ──> 専用ページ
   │
   ├── 「曲を検索」ページ
   │      └── 検索実行 ──> API (/api/search-all または artists+tracks)
   │                       ├── 最上部: アーティストカード (クリックで詳細へ)
   │                       └── 楽曲リスト: Apple Music風フラットテーブル
   │
   ├── プレイリスト / お気に入り / 履歴 / 検索結果
   │      └── createTrackCard() ──> #1バッジ削除、画像4風コンパクト行生成
   │
   └── アーティスト詳細ページ
          └── 人気曲10曲表示 ──> 行クリックで playTrack()
```

### 変更対象ファイル
- `public/index.html`: 検索結果コンテナのアーティスト枠マークアップ調整。
- `public/style.css`:
  - 旧`.track-badge`（#1など）のスタイル削除および非表示化。
  - 画像4に基づくApple Musicスタイルのトラックリスト・テーブルレイアウト（`.apple-track-table`, `.track-card`, `.track-row`）の新設。
  - ホームアーティスト候補アイテムのレイアウト更新（行クリック追加スタイル、右端`[👤 ›]`ボタンスタイル）。
  - 上下の不要な余白（`margin`, `padding`）の最適化。
- `public/script.js`:
  - `initArtistSearch`: 行クリックでアーティスト追加、右端ボタンで詳細ページ遷移に処理を反転。
  - `runSongSearch`: アーティスト検索結果とトラック検索結果を併せて取得し、最上部にアーティストカードをレンダリング。
  - `createTrackCard`: `#1`バッジを排除し、行全体クリックで即時再生するハンドラを付与。
  - `renderArtistDetailPageContent`: Top Songsを10曲に拡張し、行クリックで曲を再生するよう調整。
